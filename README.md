# 🚀 AI Job Matcher - Full Stack Microservices Application

## Technologies Used

**Frontend:**
- React 18 with TypeScript
- Vite
- TailwindCSS
- Recharts

**Backend:**
- Java 17 + Spring Boot 3.2
- Python 3.11 + FastAPI
- PostgreSQL 15
- Redis 7

**Infrastructure:**
- Docker & Docker Compose
- Microservices Architecture

## Quick Start

### Prerequisites
- Docker Desktop installed and running

### Run the Application

```bash
# 1. Clone or download this project
cd ai-job-matcher

# 2. Start all services
docker-compose up --build

# 3. Wait 2-3 minutes for all services to start

# 4. Open your browser
http://localhost:3000
